
# Student Grade Calculator

## Project Description

This is my Week 2 Python project.
It calculates student grades based on marks
in three subjects: Math, Science and English.

It also calculates class statistics and
provides personalized comments.

## What I Learned

1. Conditional Statements (if, elif, else)
2. Lists and List Operations
3. For Loops and While Loops
4. Functions
5. Error Handling using try-except
6. Calculating Average, Highest and Lowest
7. File Handling

## Features

- Processes multiple students
- Accepts marks for three subjects
- Validates marks between 0 and 100
- Calculates average marks
- Assigns grades from A to F
- Provides personalized comments
- Displays results in a formatted table
- Calculates class statistics
- Searches for a student
- Saves results in a text file

## Grading System

| Marks | Grade |
|-------|-------|
| 90-100 | A |
| 80-89 | B |
| 70-79 | C |
| 60-69 | D |
| 0-59 | F |

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python grade_calculator.py

5. Enter the number of students.
6. Enter student names and marks.
7. Select options from the menu.
