
# Personal Information Manager

## Week 1 - Python Basics

### Project Description
Personal Information Manager is a simple Python project that collects and displays personal information entered by the user.

### Features
- Accepts user's name, age and city.
- Stores hobby and favourite food.
- Accepts favourite colour.
- Calculates age in months.
- Displays all information.

### Concepts Used
- Python Variables
- Data Types
- User Input
- Print Statements
- Type Conversion
- F-Strings

### How to Run
1. Install Python.
2. Open the project in VS Code.
3. Run the following command:

```bash
python personal_info.py
```
