# Personal Information Manager

## Project Description

This is my first Python project. The Personal Information Manager is a simple Python program that stores and displays personal information. It asks the user for their favorite food and favorite color and displays all information in a well-formatted way.

## Project Objectives

- To understand Python programming basics.
- To learn how to use variables and data types.
- To practice input and output operations.
- To understand string formatting using f-strings.
- To perform basic input validation.
- To calculate age in months.

## What I Learned

1. **Variables:** Storing different types of information.
2. **Data Types:** Using strings and integers.
3. **Input/Output:** Using `input()` and `print()`.
4. **String Formatting:** Using f-strings and string methods.
5. **Loops:** Using while loops for input validation.
6. **Comments:** Writing comments to explain the code.
7. **Basic Calculations:** Calculating age in months.

## How to Run This Program

1. Install Python from https://www.python.org/
2. Install Visual Studio Code.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python personal_info.py
```

6. Enter your favorite food and favorite color when asked.

## Features

- Stores personal information such as name, age, city, and hobby.
- Takes user input for favorite food and favorite color.
- Validates empty user input.
- Displays information using f-strings.
- Calculates age in months.
- Displays welcome and goodbye messages.
