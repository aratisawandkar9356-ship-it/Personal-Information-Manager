# Contact Management System

## Project Description
A Python-based Contact Management System using Functions and Dictionaries. It allows users to add, search, update, delete and manage contacts.

## Features
- Add contacts with validation
- Search contacts using partial names or phone numbers
- Update contact information
- Delete contacts with confirmation
- Display all contacts
- Save and load contacts using JSON
- Export contacts to CSV
- View contact statistics
- Validate phone numbers and email addresses
- User-friendly menu system

## Concepts Used
1. Python Functions
2. Function Parameters and Return Values
3. Dictionaries
4. String Methods
5. Local and Global Scope
6. JSON File Handling
7. CSV Export
8. Exception Handling
9. Regular Expressions
10. Unit Testing

## Project Structure
- contacts_manager.py – Main application
- contacts_data.json – Contact data storage
- test_contacts.py – Unit tests
- README.md – Project documentation
- requirements.txt – Dependencies
- .gitignore – Ignored files

## How to Run

```bash
python contacts_manager.py
```

## Run Tests

```bash
python -m unittest test_contacts.py -v
```

## Export
Contacts can be exported to contacts_export.csv using the menu.

## Learning Outcomes
Learned how to create reusable functions, organize information with dictionaries, validate user input, handle JSON files and test Python programs.
